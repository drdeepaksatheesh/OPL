BASELINE

Known baseline

0 mV

The ideal teaching trace has a declared isoelectric baseline of 0 mV. Vertical measurements are therefore defined by construction.

This real LUDB example uses a baseline estimate derived from the manually delineated PR/TP isoelectric regions. The estimate is a biological reference, not a synthetic zero.

A real ECG may not provide one perfectly stable baseline across the entire trace. Select a local reference only when it is physiologically and visually defensible.

WHY THIS REAL RECORD?

Clean biological example selected reproducibly

OPL first filters LUDB records by published clinical metadata, then ranks eligible Lead-II recordings by annotated-baseline stability, high-frequency noise, and textbook-consistent polarity. It does not simply choose the prettiest trace by eye.

WHEN THE BASELINE WANDERS

“I cannot say for sure” is a valid measurement result

If no defensible local isoelectric reference can be assigned, OPL suppresses the vertical amplitude claim for that measurement. Timing remains available because it does not require the same baseline assumption.

Stable local baseline? Measure time + relative amplitude Baseline uncertain? Report time; withhold amplitude

BRIDGE TO RR / HRV

Baseline wander does not automatically destroy beat timing

If R peaks remain reliably identifiable, R–R intervals can still be derived even when slow baseline drift makes morphology or amplitude measurements uncertain. OPL will treat R-peak validation and HRV as their own downstream evidence problem.

The reasoning rule

Idealized teaching data explain what a measurement means. Real open data determine whether that measurement is actually defensible.

OPL does not force textbook certainty onto noisy physiology. When morphology or baseline is ambiguous, the uncertainty is part of the result. Downstream RR/HRV analysis is justified separately by the reliability of beat timing.
