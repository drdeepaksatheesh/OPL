Source & teaching notes OPL idealized teaching template · synthetic · 500 Hz ⌄
Model first. Notation and the measurement ruler are unambiguous. This is a teaching model, not biological validation data.
Then real physiology. A reproducibly selected LUDB Lead-II recording demonstrates that textbook-like morphology can occur in real biology.
Then uncertainty. ECG-ID preserves baseline and signal imperfections instead of forcing textbook certainty, while Stage 3 converts the signal to physical mV using the published source gain.
Then the machine. Stage 4 revisits the same imperfect recording in source ADC counts so students can connect biosignal hardware units to physiological amplitude.
Then independent practice. The learner sees a different real LUDB trace, chooses a baseline and places calipers before cardiologist annotations are revealed.
