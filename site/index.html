OPENPHYSIOLOGYLAB

Trusted data. Visible analysis. Understand physiology.

A growing collection of open, transparent Reference Labs that turn trusted physiological datasets into visible measurements, reproducible analysis and understandable physiology.

Public-site prototype · individual modules are released only after they pass the OPL release gate.

Use the instrument, not the repository

Each OPL Reference Lab begins with trusted, citable data and makes the path from waveform to physiological measurement visible. Source provenance, transformations, validation notes and citation information remain part of the instrument itself. Live hardware acquisition will later feed these same interfaces.
