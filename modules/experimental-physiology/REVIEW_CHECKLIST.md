# Scientific review acceptance

- [ ] Original source, stable identifier and authors documented.
- [ ] Correct animal species, preparation and acquisition setting.
- [ ] Captured original data master unchanged, SHA-256 calculated.
- [ ] Sampling rate/time ruler verified from an original source.
- [ ] Transducer and polarity/lever mechanics explained (do not arbitrarily invert).
- [ ] Signal quantity and exact physical units established, or not measured numerically.
- [ ] Drug/stimulation intervention and temporal markers identified.
- [ ] Noise / stimulus / recording artifacts distinguished from physiology.
- [ ] Third-party reuse rights reviewed for each binary/figure separately.
- [ ] Teaching exercise and interpretation reviewed by a physiology educator.
- [ ] Synthetic demo clearly and permanently distinguished from actual recording.
- [ ] Student access requires neither paid hardware nor animal procedures.

This is a review template, not evidence that items have passed.
