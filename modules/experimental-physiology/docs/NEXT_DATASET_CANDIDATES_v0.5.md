## Release gates for a new biological tracing

Original master, stable DOI or repository version, original SHA-256, species/preparation, physical axis calibrations and stimulus/drug markers, reuse rights for the **precise asset**, independently reproducible interpretation, and preservation of all original source credits.

Published images are never silently digitized as raw data. Synthesized tracings must remain labelled simulated. The user should need no access to expensive instrumentation or live animal procedures.
